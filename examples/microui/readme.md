# Microui Example

Demonstrates the microui immediate-mode GUI toolkit bundled with Spry.

## Features Demonstrated

| # | Feature | API |
|---|---------|-----|
| 1 | Windows | `mu.begin_window()`, `mu.end_window()` |
| 2 | Buttons | `mu.button()` |
| 3 | Labels and text | `mu.label()`, `mu.text()` |
| 4 | Sliders | `mu.slider()` |
| 5 | Checkboxes | `mu.checkbox()` |
| 6 | Text input | `mu.textbox()` |
| 7 | Popups | `mu.begin_popup()`, `mu.end_popup()` |
| 8 | Tree nodes | `mu.begin_treenode()` |
| 9 | Panels | `mu.begin_panel()` |
| 10 | Style customization | `mu.get_style()`, `style:set_color()` |
| 11 | Layout | `mu.layout_row()`, `mu.layout_begin_column()` |

## Controls

- Click and drag window title bars to move
- Drag window edges/corners to resize
- Interact with all widgets via mouse
