# Nuklear Demo

Demonstrates the Nuklear immediate-mode GUI toolkit bundled with Spry.

## Features Demonstrated

| # | Feature | API |
|---|---------|-----|
| 1 | Windows | `nk.window_begin()`, `nk.window_end()` |
| 2 | Labels | `nk.label()`, `nk.label_colored()` |
| 3 | Buttons | `nk.button_label()`, `nk.button_color()` |
| 4 | Checkboxes | `nk.checkbox_label()` |
| 5 | Radio buttons | `nk.option_label()` |
| 6 | Sliders | `nk.slider_float()` |
| 7 | Progress bars | `nk.progress()` |
| 8 | Properties | `nk.property_float()` |
| 9 | Combo boxes | `nk.combo()` |
| 10 | Text editing | `nk.edit_string()` |
| 11 | Color picker | `nk.color_picker()` |
| 12 | Charts | `nk.chart_begin()`, `nk.chart_push()`, `nk.chart_end()` |

## Controls

- Click and drag window title bars to move
- Drag window edges/corners to resize
- Interact with all widgets via mouse
- Close window or press Esc to quit
